# บอลลูนสะกดคำ ป.1

เกมฝึกสะกดคำศัพท์ภาษาอังกฤษสำหรับนักเรียน ป.1 เลือกตัวอักษรเติมคำให้ครบ เพื่อเป่าบอลลูนพาจัมโบ้ลอยขึ้นฟ้า

เล่นได้ที่ https://tonmaiii56.github.io/balloon-spelling/

- เลือกหมวดคำศัพท์ และเลือกเฉพาะคำที่ต้องการก่อนเริ่มเล่น
- ครูแก้ไขคำศัพท์ เพิ่มหมวด และตั้งค่าความยากได้จากปุ่ม ⚙️
- เล่นได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ (แตะจอ หรือพิมพ์ตัวอักษรบนคีย์บอร์ด)
